Vice Cover Studio is an offline cover maker that turns any photo into a multi-panel sunset poster with bold display lettering. Pick a layout, grade it Sunset, Neon Night, Golden Hour or Mono Noir, add a title and script line, then export the cover as a 1080×1080, 1080×1350 or 1920×1080 PNG — all on your own machine, with no uploads and no network requests.

## Run it
```sh
node serve.ts
```
(then open http://localhost:8080)
